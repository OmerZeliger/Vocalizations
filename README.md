# Vocalizations

Gottardi/Geffen labs vocal cords repair collaboration



Variables:

Cage Number - ID number assigned to each rat cage.

Mark - Marking used to distinguish between rats in a cage.

Age Rec 1 - Age (weeks) at time of first recording

Rec 1 Name - file name of first recording

Treatment? - 0 = Sham (no scar, no treatment), 1 = scar only, 2 = scar + empty gel (vehicle control), 3 = scar + DCN gel

AGE REC 2 - Age (weeks) at time of second recording

REC 2 NAME - file name of second recording

SCAR SCORE - 0 = no scar, 1 = minimal scarring, 2 = average scarring, 3 = excellent scarring
